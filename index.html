Taskhand, a project agent that re-plans as it goes

Give the agent a goal. It picks tools, checks what happened, and changes its own plan when a step fails. Nothing here is a fixed script: the loop is think, act, observe, repeat.

Goal

Tools

  • create_task adds a task
  • assign_task sets an owner, checks capacity
  • check_workload finds overloaded people
  • summarize counts progress and overdue work
  • flag_overdue flags and reschedules late tasks

Agent loop

Choose a goal and run the agent. Each step shows its reasoning, the tool it used, and what came back.
